\title{Budgeted Verification and Guarded Evidence Reuse\\
\large Problem definition, conditional guarantees, and implementation boundaries}
\author{SCAR research working supplement}
\date{17 October 2026}

\begin{abstract}
An LLM game agent must decide which uncertain action rules to test, whether a
test fits the remaining task budget, and when its outcome may constrain future
plans. We formalize these three decisions using finite competing action models,
observation-contingent local policies, and context-scoped evidence. The implemented
mechanism lifts surviving compiled models back to joint semantic profiles and
filters subsequent planning problems before search. We prove conditional local
completion, action-budget accounting, and sound reuse under explicit realizability
and stationarity assumptions. These are correctness statements for the mechanism,
not a claim of global game safety, optimal game play, or novel hypothesis
elimination. Controlled examples demonstrate a change in later actions; the
chronological game audit has not yet demonstrated a reuse benefit. The earlier
candidate-coverage supplement is archived separately and is not used to explain
the reported game scores.
\end{abstract}

\section{Problem definition and the role of the LLM}
A game exposes a public history $h_t=(o_0,a_0,o_1,\ldots,a_{t-1},o_t)$,
a remaining environment-action budget $B_t$, and an external task success signal
or task-progress measure. The experimental objective is progress or completion
within this budget. It is not identification of every hidden game rule.

From this history, the language-based agent proposes a method milestone $g$,
such as \emph{newly craft and hold a sword}. Grounding produces a finite local
problem only when the necessary public information is available. A milestone is
not assumed equivalent to the natural-language quest: obtaining ingredients is
a precondition, not an extra terminal requirement. The current implementation
uses V6/LLM target proposals and a hand-specified family of quantity/access rules;
it does not learn arbitrary action schemas from LLM text.

\begin{definition}[Local query]
A grounded query is $Q=(X,A,\Theta,b_0,g,K,H)$, where $X$ is a finite state
space, $A$ a finite command set, $\Theta$ a finite set of joint semantic profiles,
$b_0=\{(\theta,x_\theta):\theta\in\Theta_0\}$ the current candidate belief,
$g$ the local terminal predicate, $K$ the modeled state constraints, and
$H\leq B_t$ the local action budget. A profile specifies deterministic transitions
$T_\theta(x,a)$ and public observations $O_\theta(x,a,T_\theta(x,a))$.
Each issued command costs one environment action, including a failed command.
\end{definition}
An unavailable command is represented by its modeled failure transition when the
environment permits issuing it. A policy must therefore account for failures;
syntactic command availability is not success. Resources can be consumed,
produced, moved, and constrained by capacity. The old resource-only-decreasing
coverage model is not imposed here.

In the implemented domain, $x$ records location, elapsed actions, craft-event
bits, and integer milli-unit quantities in the hand, attached bag, and floor.
$K$ checks nonnegative counts, hand/bag capacities and explicitly declared
protected totals. The automatic adapter leaves protected totals empty: it does
not certify resources needed by unrelated quests. $g$ checks the new craft event
and current possession. Bag contents are observable only through the modeled
inspection operation; model IDs never appear in observations.

For ingredient coefficient $c$ and integer batch $q$, the quantity rules are
\[
 d_{\rm exact}(c,q)=cq,\quad
 d_{\rm batch}(c,q)=1000\lceil cq/1000\rceil,\quad
 d_{\rm output}(c,q)=1000q\lceil c/1000\rceil.
\]
Access rules permit hand, hand plus bag, hand plus floor, or all three. A profile
is a \emph{pair} of quantity and access rules; retaining the two marginals would
lose correlations established by an observation. Consumption priority, floor
output, fixed loads, station sufficiency, material-preserving failure and absence
of ambient effects remain assumptions of this family.

For a fresh observation $o$, update by
\begin{equation}\label{eq:update}
 b[a,o]=\{(\theta,T_\theta(x,a)):(\theta,x)\in b,\
 O_\theta(x,a,T_\theta(x,a))=o\}.
\end{equation}
An empty actual successor is model mismatch, not evidence of task impossibility.
An incomplete observation is not filled in with a preferred model prediction.

\section{Which verification actions are permitted?}
\subsection{Freeze the original obligations}
At query admission fix $b_0,H,g,K$. In strong mode all profiles must reach $g$.
In opportunity mode let $E_0$ contain only profiles with a proved absence of a
$K$-respecting goal trajectory within the \emph{original} horizon $H$. Let
$R_0=\supp(b_0)\setminus E_0$. An unresolved individual search remains in $R_0$.
Both sets are frozen throughout this trial. No new exemption is granted after
an action has consumed material or time. Exempt worlds still constrain $K$ and
observations. If $R_0$ is empty, the controller does not select a verification
trial on the basis of a vacuous completion requirement.

An exemption is relative to this fragment and horizon. Unmodeled upstream
recipes, remote resources, or another method may still solve the full game.
Exemption is neither falsification of a profile nor global infeasibility.

\begin{definition}[Admissible verification prefix]\label{def:admit}
Let $p$ be a command prefix whose public observations first split the surviving
profiles at its last action, and let $k=|p|$. It is admissible when:
\begin{enumerate}[label=(\roman*)]
\item every intermediate state along every modeled prefix execution satisfies $K$;
\item for each resulting observation leaf $o$, there is a \emph{single}
observation-based suffix policy $\pi_o$ that satisfies $K$ in every world in
$b_o$, and reaches $g$ for every surviving profile in $R_0$;
\item $k+\max_o\cost(\pi_o,b_o)\leq H$.
\end{enumerate}
The cost of a policy is the maximum path length over all its candidate worlds,
including exempt worlds. A leaf with only exempt worlds may stop without $g$,
and must be reported as such.
\end{definition}
The central quantifiers are $\forall o\ \exists\pi_o\ \forall\theta\in b_o$.
The weaker $\forall\theta\ \exists\pi_\theta$ permits an omniscient choice and
does not certify a usable experiment. The implementation searches bounded
nonbranching preparations up to the first split; it does not enumerate all
possible experimental policies.

\begin{theorem}[Conditional local completion]\label{thm:local}
Assume (a) the true grounded world belongs to $b_0$; (b) its transitions and
observations agree with its candidate throughout execution; (c) the grounded
state, $g$, and $K$ have their declared meanings; and (d) the certified commands
are executed without unmodeled interventions. Executing an admissible prefix
and its observed suffix maintains $K$ and terminates within $H$. If the true
profile belongs to $R_0$, termination satisfies $g$.
\end{theorem}
\begin{proof}
Initially the true pair belongs to $b_0$. By (b) and (d), each issued command
produces its modeled successor and observation. Equation~\eqref{eq:update}
therefore retains that pair, inductively. Condition (i) covers the prefix;
condition (ii) covers all suffix states and its required terminal goal. The
observed leaf determines one common policy, so no hidden identity is needed.
Condition (iii) bounds the entire path. An exempt true profile is covered by the
constraint and cost argument, but not by the goal conclusion.
\end{proof}
The theorem is deliberately local and conditional. In the actual game,
\texttt{MODEL\_MISMATCH} and \texttt{OBSERVATION\_GAP} stop further certificate
use. Detection after an action cannot undo that action or prove it was safe.
The fallback LLM policy does not inherit this local theorem.

\section{Why spend the action budget on verification?}
\subsection{An implemented budget guard, not a value-of-information claim}
Let $\pi_{\rm ref}$ be a replay-verified common policy for the same query and
frozen obligations, with worst path cost $C_{\rm ref}$. A proposed experiment
with certified suffixes has
\begin{equation}\label{eq:cost}
 U(p)=|p|+\max_o\cost(\pi_o,b_o).
\end{equation}
The current selector requires
\begin{equation}\label{eq:allowance}
 U(p)\leq H,\qquad U(p)\leq C_{\rm ref}+\Delta
\end{equation}
when a reference has been found. $\Delta=0$ in the game runs. When no reference
has been found, only the horizon and admissibility tests apply. Failure to find
a reference within a computation budget is not proof that none exists.

\begin{proposition}[Budget accounting]\label{prop:budget}
Under Theorem~\ref{thm:local}'s assumptions, an admitted experiment consumes at
most $U(p)$ environment actions. If a reference exists, its worst-cost overhead
is at most the declared allowance in the sense of~\eqref{eq:allowance}.
\end{proposition}
\begin{proof}
Every execution consists of the $|p|$ charged prefix commands and one verified
suffix path. The latter is no longer than its leaf's verified maximum. Maximizing
proves~\eqref{eq:cost}; the selector explicitly checks~\eqref{eq:allowance}.
\end{proof}
$C_{\rm ref}$ is an upper bound from an existing witness, not an optimal cost or
a lower bound. This proposition does not establish pointwise dominance over
$\pi_{\rm ref}$, improvement in expected game score, wall time, or API cost.
The selector ranks admissible experiments by worst total cost, remaining model
count, excess production, and prefix length. The information tie-break is a
heuristic: cardinality alone is not the benefit being optimized in the game.

\subsection{When information can change a later decision}
For a \emph{fixed} query state, horizon and frozen obligations, let $V_R(b)$ be
the optimal worst action cost of a common policy satisfying those obligations,
or infinity if none exists. Restricting the belief also restricts required
profiles to $R\cap\supp(b)$; it never creates a new exemption for a retained one.

\begin{proposition}[Decision value under sound elimination]\label{prop:monotone}
If $b'\subseteq b$ consists of the same retained profile--state pairs, then
$V_R(b')\leq V_R(b)$. The inequality need not be strict. This statement does not
compare the state before a resource-consuming experiment with the state after it.
\end{proposition}
\begin{proof}
Any feasible policy for $b$ can be restricted to observation paths reachable from
$b'$. Its constraints and terminal obligations continue to hold and its maximum
path length cannot increase. Taking minima proves the result, including the
case $V_R(b)=\infty$. A costly experiment changes states and remaining horizon,
so the subset premise does not hold for that comparison.
\end{proof}
A finite search budget may return a worse witness despite a smaller exact
optimum; the proposition is about $V_R$, not every bounded solver run.

\begin{example}[A decision-relevant and a decision-irrelevant distinction]
A blade needs one unit of ore, available only in an attached bag. The rules are
hand-only and hand-plus-bag. Without distinguishing them, the common policy is
\emph{take out ore; craft; pick up blade}, costing three actions. Sound prior
evidence for hand-plus-bag permits \emph{craft; pick up}, costing two, in the
same later state. If the ore is already in hand, both rules permit the same
two-action policy: identifying access gives no action saving there.

Testing \emph{craft} in the bag-only state succeeds under one rule, but under
hand-only it fails and still requires the three-action policy. Its worst cost
is four, so a zero-allowance guard rejects this test against a three-action
reference. Information is not automatically worth its acquisition cost.
\end{example}

\subsection{A sufficient amortization condition, with explicit limits}
The following is a proposed analysis tool, not a deployed test-selection rule.
It states what must be estimated before justifying a positive allowance by
future reuse. Suppose a finite sequence of future query states and budgets is
specified. For each true profile, both strategies reach the \emph{same} next
query state, or any additional routing/replenishment cost is included explicitly.
All guards remain valid; policies and their path costs can be replayed for every
profile. These assumptions are not established for arbitrary game progression.

For profile $\theta$, let $C_{0}^{\rm test}(\theta)$ and
$C_{0}^{\rm ref}(\theta)$ be acquisition-episode costs including completion, and
$C_j^{\rm reuse}(\theta),C_j^{\rm ref}(\theta)$ later episode costs.
Set
\[
 e=\max_{\theta}\bigl(C_0^{\rm test}(\theta)-C_0^{\rm ref}(\theta)\bigr),
 \qquad
 s_j=\min_{\theta}\bigl(C_j^{\rm ref}(\theta)-C_j^{\rm reuse}(\theta)\bigr).
\]
These are pathwise comparisons with verified \emph{specified policies}, not
differences of unrelated upper and lower bounds.
\begin{proposition}[Sufficient amortization]\label{prop:amortize}
Under the stated matched-query assumptions, if $e\leq\sum_{j=1}^k s_j$, the
test-and-reuse strategy costs no more than the reference strategy for any
candidate profile across these episodes. Each episode must separately satisfy
its actual remaining budget and constraints.
\end{proposition}
\begin{proof}
For each $\theta$, subtract total reference cost from total test-and-reuse cost.
The acquisition difference is at most $e$ and each later difference is at most
$-s_j$. Their sum is at most $e-\sum_j s_j\leq0$. Matching boundary states (or
charging all differing boundary costs) makes this sum describe the two actual
strategies. A total-cost inequality alone does not ensure an intermediate
budget or resource constraint, which is why these require separate checks.
\end{proof}
The condition may fail: the hand-only branch in the example saves nothing in
later episodes. Without a justified distribution or guaranteed revisits, a
successful-branch saving cannot pay for a failed-branch loss. Current software
therefore uses the explicit local allowance, not a claimed estimate of future
information value. A future empirical estimator must report prediction error
and acquisition costs rather than treating every elimination as a benefit.

\section{When may learned evidence be reused?}
\subsection{Context-scoped raw profiles}
A context guard $\kappa(Q)$ describes the assumptions under which semantic
parameters are treated as stationary. The implemented guard includes recipe
identity and quantities, station evidence, location/routes, item vocabulary,
equipment and bag identity, capacities/background loads, semantics version and
raw profile universe. It excludes current inventory quantities, public-history
length and offered batch sizes. These excluded fields are re-grounded for each
new query; they are not copied from an old state. Changes to included fields
prevent cross-context filtering.

Equality of these recorded fields does \emph{not} prove guard adequacy. Time,
level, buffs or other unmodeled variables may affect a craft. In particular an
observed evening bonus in Mark falls outside the current family. A valid reuse
theorem requires that any excluded variable either is modeled as state or does
not change the shared semantic parameters. The current game system has not
established that assumption generally.

\begin{definition}[Evidence ledger]
For a context $\kappa$ and validity epoch $e$, let $\Theta_\kappa$ be its raw
joint profile universe and $S_{\kappa,e}$ its current survivors, initially
$\Theta_\kappa$. A matched public transition $i$ defines compatible raw profiles
$C_i$ by replay against the pre-observation belief. Update
\begin{equation}\label{eq:ledger}
 S_{\kappa,e}\leftarrow S_{\kappa,e}\cap C_i.
\end{equation}
Each update stores the action, observation digest, local compilation fingerprint,
context/epoch, and eliminated joint profiles. Search infeasibility and unresolved
search are not transition evidence and cannot enter this update.
\end{definition}
A new query with the same context compiles only its profiles in $S_{\kappa,e}$.
Thus evidence changes available future policy branches and the selected action,
not merely a textual memory entry. The implementation supports one recipe per
persistent query; it does not independently factor multi-recipe correlations.

\subsection{Aliases must survive changing action sets}
The compiler may collapse profiles with identical behavior in a query. For
example, the two rounding rules coincide when only batches of size one are
available. Names such as \texttt{m0} are local to that compilation, not stable
semantic identities. Let $\alpha_Q(m)$ be all raw aliases represented by model
$m$. For surviving compiled models $M_i$, use
\[
 C_i=\bigcup_{m\in M_i}\alpha_Q(m)
\]
before applying~\eqref{eq:ledger}. Filter raw profiles \emph{before} quotienting
the next query; its different batch set may split an old equivalence class.

\begin{lemma}[Alias lifting]\label{lem:alias}
Suppose a compiled class represents exactly the same transitions and observations
as all its raw aliases on every action/state reachable within the current
query's horizon. Retaining the union of aliases of matched classes does not
eliminate a raw profile consistent with that query's actual observations.
\end{lemma}
\begin{proof}
Any consistent raw profile belongs to a class making the same predictions along
the actual path. That class survives every matching observation. Its entire
alias set is retained, including the profile. No choice of a single canonical
representative is transferred to a later, possibly finer query.
\end{proof}
For no attached bag, bag-inclusive and bag-exclusive access modes may collapse;
the aliases still preserve their unresolved distinction. For an integer-unit
recipe all quantity rules coincide; for noninteger coefficients and unit batches,
only the two ceiling rules coincide. These are the compiler's declared reductions.

\begin{theorem}[Guarded reuse]\label{thm:reuse}
Assume a fixed epoch has a true raw profile $\theta^*\in\Theta_\kappa$; all
recorded transitions are faithfully observed and modeled under that profile;
the guard is adequate to keep these semantic parameters valid in every query
using the epoch; and the compiler satisfies Lemma~\ref{lem:alias}. Then
$\theta^*\in S_{\kappa,e}$ after every valid update. Filtering a later matching
query by $S_{\kappa,e}$ therefore does not remove its true profile. With fresh
correct grounding, Theorem~\ref{thm:local} applies to a newly verified policy in
that filtered query.
\end{theorem}
\begin{proof}
The initial survivor set includes $\theta^*$. At each matched observation,
correct transitions and observations keep its compiled class alive. Alias
lifting places $\theta^*$ in $C_i$; intersection preserves it. Induction proves
the first statement. Guard adequacy transfers the same parameter interpretation
to a new query, whose states and constraints are re-grounded. Filtering happens
before recompilation, so the true profile remains represented even if the new
quotient differs. The new certificate, not the old action sequence, supplies
its own completion and budget argument.
\end{proof}
Observations may repeatedly fail to distinguish surviving profiles. The theorem
does not imply identification, fewer LLM calls, or a bound on total game failures.
For a fixed finite nonempty universe, there are at most $|\Theta_\kappa|-1$
strict eliminations in a realizable epoch. This elementary finite-elimination
fact is not a sample-complexity or novelty claim. Changing contexts, expanding
the family and opening new epochs void any across-run version of that count.

\subsection{Invalidation and recovery}
All-model mismatch, incomplete modeled feedback, or incompatible checkpoint
execution revokes the epoch's exclusions; the controller cancels its current
continuation. The ledger keeps the audit, restores the unfiltered family for a
fresh epoch, and makes no claim that the family is now correct. Different
contexts use separate ledgers. Model-family expansion changes the universe and
requires new validation. Restoring a checkpoint preserves the frozen filter,
epoch, spent actions, original exemptions and feedback replay; it must reproduce
the policy fingerprint before continuing.

Revocation is conservative: combat can revoke evidence even when the quantity
rule did not actually change. Conversely a hidden change that continues matching
some false profiles can remain undetected. Neither clearing a ledger nor a
successful subsequent action repairs a missing true model. The present mechanism
is exact elimination under assumptions, not probabilistic belief revision.

\section{Algorithm and correspondence with implementation}
\begin{enumerate}[label=\arabic*.,leftmargin=*]
\item Read public history and the remaining global budget. V6/LLM proposes the
method milestone; ground its supported fragment. On missing evidence, return
\texttt{GROUNDING\_UNKNOWN} without pretending that a trial was certified.
\item Compute the context and read its current raw-profile survivors. Compile
fresh quantities, resource constraints and observations using the surviving
\emph{joint} profiles; retain all behavioral aliases. Abort on compilation limits.
\item Fix the original goal-required profiles. Find and replay a common reference
policy if possible. Enumerate bounded first-split prefixes; require one verified
common continuation per leaf and the horizon/allowance tests.
\item Execute the selected command; charge its action immediately. Match fresh
public feedback to predicted branches. On mismatch/gap, revoke the epoch and
cancel continuation. Do not reinterpret these events as task completion.
\item On a matched transition, lift surviving aliases and update the ledger
immediately, before the whole local trial completes. Follow its certified
observation branch without a new LLM call when possible.
\item At later queries, apply this ledger before search. Re-ground state and
re-verify a new policy. Never transplant an old plan solely because its evidence
context matches. Preserve global action expenditure across all queries.
\end{enumerate}

\paragraph{Implemented.}
\texttt{resource\_competition.py} defines the finite semantics, constraints,
paired-profile filter and bounded experiment selector.
\texttt{resource\_trial.py} grounds one recipe at the current observed station
and follows actual feedback.
\texttt{resource\_evidence.py} implements guard/epoch ledgers and alias lifting.
\texttt{resource\_agent.py} adds the opt-in
\texttt{persistent\_resource\_v9} agent with checkpointed evidence; V8 remains
available. The persistence intervention adds no new LLM call or evidence prompt
section; it directly changes compiled candidates. Later history can of course
diverge after actions change. Existing limits are six grounded searches per run,
a six-action local horizon and a 300-action global development budget.

\paragraph{Conditional properties.}
Theorems~\ref{thm:local} and~\ref{thm:reuse} require realizability, faithful
observations and adequate guards. Proposition~\ref{prop:budget} applies to
modeled action counts. Proposition~\ref{prop:monotone} concerns an exact optimum,
not bounded-search wall time. Proposition~\ref{prop:amortize} requires specified
future matched queries and pathwise costs; it is not an implemented scheduler.

\paragraph{Not implemented or not established.}
Automatic upstream/cross-location grounding, automatic guard discovery,
time-dependent rule inference, multi-recipe persistent correlations, full-quest
safety/completion, a learned estimate of future reuse value, and independent
full-game benefit of persistent evidence remain open. Generic route/upstream
support in the finite domain does not establish their automatic game grounding.
LLM-plus-planner composition and safe action-model learning have prior
precedents~\cite{dagan2023,juba2021,mehta2011}; the above correctness results do
not establish independent originality.

\section{Validation and current evidential limits}
The new tests check correlated-pair filtering, alias lifting when batch sizes
change, count changes versus guarded context changes, mismatch revocation,
rejection of search results as evidence, checkpoint replay, and integration with
matched prompts. Existing tests cover destructive probes, paid hidden-container
observations, frozen exemptions, UNKNOWN retention and exact small-model oracles.

The zero-API audit in \texttt{audit\_persistent\_evidence.py} separates two kinds
of evidence. Two constructed bag-access instances (hand capacities one and two)
produce a verified three-action later plan without reuse and a two-action later
plan with correctly acquired accessible-bag evidence. The acquisition experiment
has worst cost four and explicitly uses allowance one; that extra allowance is
not enabled in the full-game configuration. These are mechanism examples with
modeled observations, not independent game episodes or an amortization result.

The chronological replay of all 11 grounded queries from the completed V8 game
runs feeds only earlier actual public feedback into each ledger. It produces
\textbf{zero reused later queries and zero changed decisions}. Subsequent
same-recipe contexts differ in attachment/equipment, other recipes are not
repeated, and some evidence is revoked after feedback gaps. Filtered-policy
outputs are offline counterfactual queries; historical outcomes are never claimed
to result from their actions. This negative result rules out attributing those
completed game scores to persistent evidence.

The earlier V8 run scores were 2, 17 and 17 for Remnant, Mark and Metropolis;
Mark completed the environment. The frozen V6 scores were 3, 17 and 9. Those
runs motivate further game evaluation but have prompt/sampling differences and
are not a causal ablation of the new mechanism. No unchanged baseline was rerun.
The next efficacy test needs repeated applicable opportunities, matched initial
states and prompts, charged acquisition costs, and real quest outcomes. A smaller
candidate set, a cheaper local witness and improved full-game completion are
three distinct endpoints.
