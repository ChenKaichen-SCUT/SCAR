## 直接工程入口

以下为后续运行器的调用合同；真实 provider 与环境由调用方提供，不由本模块创建。本轮没有执行真实环境或付费调用。

```python
from scar_stage16.agent import make_agent
from scar_stage16.config import BaselineConfig

agent = make_agent(
    provider=my_provider,
    game="robot_kingdom",
    config=BaselineConfig(variant="S1_P1_P3", seed=42),
    memory_dir="/path/to/agent_memory",
)
agent.initialize_episode(
    history=public_history,          # before/action/after，真实公开前缀
    target_action=target_action,
    public_goal=public_goal,
)

view = agent.public_state           # 只读快照
recipe = view.get_recipe(item)
gaps = view.get_missing_knowledge()

# 由原游戏调用约定执行一次提案与控制；返回值与旧 STM Agent 相同。
action, input_tokens, output_tokens, raw_response = agent._act(observation)
# 调用方执行 action 并获得真实 after_observation 后：
agent.observe_transition(observation, action, after_observation)
agent.save_memory("/path/to/checkpoint")
```

provider 必须实现 `generate(user_prompt=..., system_prompt=...)`，返回包含 `response`（JSON 文本，含 action）、`num_input_tokens`、`num_output_tokens` 的字典。真实请求须使用冻结的模型、温度、token 上限和 thinking 设置；离线可以使用 `scar_stage16.replay.RecordedProvider`。不依赖 Stage15 的 provider／批次入口。

恢复时以同一 variant、游戏和冻结参数创建 Agent，再执行 `load_memory(checkpoint_dir)`。`memory.json` 保存 STM，`baseline.json` 保存版本、配置、控制器、事实表和提示；配置不匹配会拒绝恢复。`set_recovery_objective` 保留旧状态设置语义；推荐新回合使用 `initialize_episode`，不要重复追加历史或目标提示。

## 证据文件

- `checkpoints.jsonl.gz`：47 个自包含公开检查点、原提案／回答、预期动作、原前置控制器、事实和 STM、原请求 messages、来源定位及哈希。
- `chain_net_branch.json`：保存的原生分支公开前置状态、三个动作与反馈。
- `replay_local.json`、`replay_server.json`：逐状态验收及状态/提示哈希，两份内容完全相同。
- `unit_tests_local.txt`、`unit_tests_server.txt`：测试输出。
- `coverage.json`：39 个 P3 检查点的覆盖标签；冲突边界只在合成单元测试出现。
- `historical_manifest.json`、`freeze.json`、`publication_manifest.json`：历史保护、基线冻结和发布清单。
- `server_integrity.json`：服务器源码/历史文件与实验账本、任务输出的哈希验收。

这些文件只包含本项目实现及已有实验的必要公开记录和分析，不包含密码、API 密钥、下载的引擎或模型。
