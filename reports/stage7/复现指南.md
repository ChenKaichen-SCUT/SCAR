# Stage 7 复现指南

## 环境

使用 Python 3.12 及原项目依赖；下载的 AgentOdyssey 不提交到此仓库，上游固定提交为 `248430692a9d4a61d38c6c03ab2126287faaf450`。`AGENTODYSSEY_ROOT` 指向该引擎仓库，并按原工程方式将其安装到虚拟环境。设置 `PYTHONHASHSEED=0` 和 CPU 数值库单线程。

```bash
export AGENTODYSSEY_ROOT=/path/to/agentodyssey
export PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m pytest tests/test_stage7.py tests/test_unknown17.py tests/test_sequence.py -q
```

Stage 7 从 `44297e6` 开始，历史源文件和结果不得改写。`results/stage7/freeze.json` 固定决策策略、代理、运行器、配置、离线入口和测试；独立后处理脚本以最终 `artifact_manifest.json` 固定。正式结果未用于修改策略。

## 零 API 恢复与逐步重放

```bash
python -m scar_unknown17_stage7.reproduce --runtime /tmp/scar-stage7-replay --replay-saved
```

此命令恢复已发布的 17 个实验初态，执行六配置的已保存动作，逐步比较完整物理状态哈希，不调用语言模型。生成的 `restoration.json` 给出 102 局及全部动作重放结果。原始初态位于已发布的 `results/sequence/dataset/initial_states/`；这些是我们生成的实验快照，均剥离模型对象及配置。仅反序列化可信本仓库快照。

单元/离线检查与正式成功率分离：`offline_checks.json`、`quantity_regressions.json` 和 `fixed_suffix_checks.json` 证明实现或局部物理效果。`trajectories_C*.jsonl.gz` 与 `requests_C*.jsonl.gz` 才是实际模型闭环及用量。每行轨迹包含一个完整 episode，包括公开观察、基础候选、执行动作、控制器检查点、公开事实摘要、反馈和评测真值。后者从未传给策略。

## 决策级反事实

`decision_counterfactuals.jsonl.gz` 保存每个正式决策四次单开关比较。起始控制器状态、公开观察、基础提案完全相同；仅切换一个布尔开关。动作发生变化时，两个完整环境单步都保留反馈和物理结果。`decision_examples.jsonl.gz` 和 `counterfactual_states/` 保存每局每模块第一个动作差异的可复现实例。完整局部审计可先恢复初态并执行相应主轨迹前缀，然后使用该行的 `stage7_state_before` 及已记录的 `proposed_action` 重算。

局部审计中“临时启用”不补造过去未启用模块的内部历史，零触发不代表该模块在整局开启时无效。局部胜负不可当作整局恢复率。

## 正式实验协议

`configs/protocol_stage7.json` 明确列出 C0–C5 开关、原 17 个 family、40 步、STM 5、temperature=0.7、max_tokens=768、DeepSeek Flash 非思考模式。只能按完整矩阵执行；不得挑失败重跑、追加种子或放宽步数。已有历史“不要重跑独立基线”的要求保留；C0 是必须同批运行的原版内部对照。

如在另一次明确授权的复现实验中需要重新调用模型，可使用全新运行目录及独立密钥路径：

```bash
python -m scar_unknown17_stage7.reproduce \
  --runtime /path/to/new-runtime \
  --run-closed-loop --key /private/path/to/key
```

该命令要求全新运行目录，会产生新费用和新的随机采样结果，不能冒充本次原始结果。不要对原正式目录再次运行付费入口：冻结 runner 的原始 failed 标签并不了解事后的方法中止分类，不能将已确定的策略递归误当成可重试基础设施故障。本轮实际正式目录为 `/root/scar_workspace/runtime_stage7`，增量账本硬上限 $5；账本数据库与凭据不上传。所有相对费用均使用协议固定历史记账价格，不是当前供应商发票。

## 汇总和独立验证

有完整服务器检查点时：

```bash
python -m scar_unknown17_stage7.evaluate --runtime /path/to/runtime
python -m scar_unknown17_stage7.decision_audit --runtime /path/to/runtime
python -m scar_unknown17_stage7.analyze --runtime /path/to/runtime
python -m scar_unknown17_stage7.verify --runtime /path/to/runtime
python -m scar_unknown17_stage7.report
python -m scar_unknown17_stage7.publication
```

`verify` 的累计费用对账引用原服务器前三个历史账本；离线可移植重放使用上面的 `reproduce --replay-saved`，不依赖这些私有账本。报告同时保留全部 17 例、新增恢复与反向退化、旧共同失败 11 例的 7/4 分组。未转化的规则按发现后剩余至第 40 步截尾，不只统计成功轨迹均值。

## 方法中止保留

正式批次中 `spire_pike / C5` 在 26 个已提交动作后遇到探索与工作台查询递归。冻结运行器原始状态为 `failed`；`failure_audit.py` 从原检查点和该次已付费基础提案两次零 API 重现 `RecursionError`，因此评测明确归类为方法中止并计入 17 例分母。原始状态、错误栈、未执行环境动作的请求费用均保留，未修复策略后补跑。
