# 统一API和执行协议

全部LLM方法使用DeepSeek官方兼容地址 `https://api.deepseek.com` 和 `deepseek-flash`，temperature=0.7、thinking disabled。常规动作输出768 tokens；Ada完整计划/检查/修订2048，续行和计划内询问768。参数、消息、原始响应、返回模型、缓存/输入/输出token、错误与重试、费用及决策step/ordinal/phase均保存。A4不用API。

每项任务各方法共享物理种子、初始状态、目标文本、完整公开前缀、动作接口与100步上限。成功必须由独立引擎状态证明：评估期累计真实制作目标数量≥1且实际拥有≥1。地面成品不算持有。正常成功停止；否则100步或游戏终局/第一次死亡停止。原引擎可自动复活，死亡以原生reward.death事件判断，不能仅检查观察后的健康值。实际环境动作全部计数，包括拒绝、wait、检查、失败制作和移动。计划和模型调用不算动作，但全部计费。不得以模型自报成功判定任务。

初始公开信息不按知识完整度分组，不注入离线配方。A0内部收尾剩余预算同步改为100，其他策略保留。A1保留STM5；A2保留全部历史且无截断，若API拒绝超窗则记录异常并保留分母。A3不任意执行Python，不重置物理环境，显式记录计划版本、变量、断言、偏离、修订和续行。

每个逻辑请求最多3次网络/JSON结构解析尝试；所有方法相同。400/401/402/403/404/422等明确拒绝不盲目重试。失败与格式错误也计费；用量不明按预留保守上界记账，不能当免费调用。执行器采用共享SQLite预留账本和最多12个在途API请求。正式任务按冻结随机顺序交错提交10个独立进程；每个进程只有一个游戏Agent。多任务并发不是多智能体算法。

断点在每个真实动作后保存物理状态、随机状态、方法记忆、公开证据和完整轨迹；已收到的付费模型答案按固定逻辑请求序号及请求哈希复用。恢复后请求变化即报错，不重采样答案。已结束失败任务不重跑。中断时无法确认是否收到计费响应的请求标记uncertain并停止该局，保留此前动作与费用预留。异常任务保留分母。正式运行不因成绩改任务、提示、策略或步数。

费用参考 [DeepSeek官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，协议统一采用每百万tokens峰时价格：缓存命中$0.006、未命中$0.3、输出$1.2。实际非峰时账单可能更低；报告的是可复算协议费用。根据2207条Stage15历史请求与旧任务提示增长测量，无缓存、无重试场景约$35，其中LongContext约$24；实际缓存、早停和计划修订会改变费用，估算不是承诺。用户已取消此前$20上限。为防异常失控，冻结统一$200总预留保护、每模型局$12；触发后按预算中止记录，不能只展示有利结果。实测连通性为旧bandage_roll任务上的3次请求，单列费用，不进入正式120组。

每步只读包装原生action dispatch一次，以区分动作阶段实际材料消耗和后续世界动态，不修改参数、反馈、状态或随机数；在保存快照前卸下包装。与未插桩原生step比较状态哈希验证一致。隐藏物理评测仅写日志，不传给算法。

统计代码随冻结提交固定：R@60/80/100分母各24；成功步数分布与全体动作、token/成本同时报告。按任务配对并按游戏、目标family、依赖深度分层。相关任务及单次模型采样限制推断；配对检验与名义Wilson区间只作探索性参考。原始重复检查与相同反馈重复检查分别记录，不自动认定重复即浪费。规则闭包覆盖分别报告关系、数量、站点，原始文本可访问不等于模型理解。

运行：设置 `AGENTODYSSEY_ROOT` 指向固定官方引擎，`PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=.`。使用固定虚拟环境执行 `python -m scar_stage17.batch --runtime /root/scar_workspace/stage17_runtime --workers 10`。已有正式summary的任务自动跳过；不得删除后重跑。批次结束自动汇总和服务端原生重放，随后同步原始结果至本地进行独立重放，再提交GitHub。离线复核无API费用。
