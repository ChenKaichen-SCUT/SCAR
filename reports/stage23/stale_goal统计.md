# stale goal 统计

按用户确认的口径，保留原 goal、事实表、STM5 和模型输入生成链，只解除原“未解决证据时保留默认动作”仲裁分支的旧目标约束。公开条件 REJECT、库存/路线/材料检查及其他原控制逻辑仍保留；它们仍可能返回与旧目标有关的动作。因此 Oracle 是时机参照，不是解除全部控制限制后的数学上界。

母轨迹 a31 登记 `enter hall`，a32 起出现已在目标地点却保留原目标的 stale 状态；三个版本 goal 文本均持续到 a300（a31–300 共 270 次决策）。这不是 reset 未触发，而是用户指定保留原结构化输入的结果。
