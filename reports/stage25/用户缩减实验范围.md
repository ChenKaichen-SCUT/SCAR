# Stage25 范围修订

用户在正式运行中明确要求：“不要跑9局，只跑3局，每个游戏一次”。因此仅保留 remnant/mark/metropolis 的 seed42 三局；取消 seed43/44 六局。原九局预登记和冻结提交保留作为历史记录，本文件及 scope_amendment.json 是最终有效实验范围。

取消通过各局账本的写入拦截实现：已经发出的请求允许返回并结算，下一次请求在发送到模型 API 之前停止，不杀死正在计费的连接、不浪费已付费响应。原运行器将该受控停止记录为基础设施异常；其研究口径明确重分类为 user_cancelled，不视为算法失败，也不参与正式成绩。所有已发生请求、轨迹和费用单独保留。

算法、模型参数、置信度阈值、300 步上限均不修改。三个 seed42 仍从已配对的原初态开始，既有 Stage18 与 Stage24 不重跑。取消不是根据分数筛选。

判定沿用原奖励门槛，但按每游戏一次观察：完整改善要求 mark≥11 且第一章完成、remnant>1 且未因动作可靠性硬条件终止、metropolis≥7 且第一章完成；部分改善要求某游戏相对 Stage24 主线增加≥1，或 remnant 不因动作可靠性硬条件终止且奖励≥1。不再使用三种子均值、2/3 或 3/3 条件。不据单次采样宣称显著性或稳定泛化。

后续不调用原 frozen batch 入口启动九局。复现正式实验应逐游戏显式使用 `--seed 42`；离线分析以 scope_amendment.json 的 formal_cases 为准。
