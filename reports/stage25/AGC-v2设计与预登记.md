# Stage25：AGC-v2 设计与运行前协议

冻结前写入本协议。完整保留 Stage24 与 Stage18，新增 agents/agc_v2 与 scar_stage25。用户另行确认：公开证据不匹配降为低置信度信号，记录可核验性，不仅因引文格式拒绝语法合法动作。

## 要检验的假设与已有证据

Stage24 mark 最终主线 11、a118 完成第一章；remnant 主线 1、91 动作后因两次非法 write 格式终止；metropolis 主线 4，a82–300 长期持有同一材料收集目标。metropolis “过度 reset 打断正确计划”尚未被既有轨迹证实，作为假设审计，不能先当作因果事实。Stage24 的非法 write 未执行到环境，准确链条是模型提案被 AGC 语法门槛两次拒绝后终止，不是正式轨迹中两次环境拒绝。

## Confidence-aware Goal Control

继承 AGC 的五字段目标记录，增加 confidence∈[0,1]。初始为 0.70；未能核验的引文对应 0.35 上限。公开证据仅在当前/最近五条真实观测或已验证目标引文中做空白规范化子串匹配；未核验引文不能在下一步自我证明，不能回流为“环境公开事实”。

只读取公开文本，保留原有界状态签名、失败记录、STM5。成功执行字面目标动作或到达字面 enter 目的地，目标 COMPLETED、置信度 1；与字面动作对应的明确永久不可能反馈使目标 INVALID、置信度 0。新的明确公开指令仍按原机制替代旧目标，属于正常公开指令更新而非固定步数 reset。

其余实际动作后的增量：新颖且与目标词汇相关的公开事件，或新状态中的目标相关手持/装备数量增加，+0.08；普通公开失败 −0.08，同动作/同公开上下文累计失败≥2 时 −0.12；没有新公开信息 −0.06；有新信息但没有可识别目标关联 −0.02。词汇匹配只基于目标文本和实际观测，排除普通功能词，不使用物品/NPC/地图词表。它是启发式相关性代理，不是校准概率，也不保证语义蕴含或主线进度。

阈值在本文件写入前即取建议中值 **0.40**。使用保存的 Stage24 固定动作序列，对 0.20/0.40/0.60 做零 API 离线触发统计；这些不是不同阈值下的新模型轨迹，不能据此估计分数或选择胜者。正式试验只使用一个阈值，不按付费结果调参。

confidence<threshold 表示 SUSPICIOUS，并请求同一模型重新评估；没有任何“到第 N 步就清空目标”的规则。高置信度目标不会被计时器清除。模型仍可自主更换目标，控制器不强迫保留、不生成新目标，不能把置信度变成新的 stale goal 硬锁。目标重评估最多额外一次；模型再次选择原目标且动作合法时允许执行并记录软限制放行。因此，减少目标切换是待观察结果，不是代码保证。

## Action Sanity Filter

共用已有公开动作签名检查，检查 JSON 是否有 action、参数数目/引号语法、goal_description 是否有效；检测最近两个实际动作是否在同一公开上下文完全相同且均明确失败。上下文改变后不永久禁止该动作。不访问原生隐藏可执行性、配方或任务图，不添加环境实体假设。

拒绝后使用相同原提示与同一公开状态，只追加：

```text
Previous action was invalid.
Please generate another valid action.
```

不附带推荐动作、修正后的参数、攻略或替代计划。每个环境决策最多 **3 次动作重试**；最多另加 **1 次目标重评估**，故最多 5 次请求。持续违反硬条件时保留原失败记录并终止，不自动 wait，不跨冻结版本修复后再试。goal_description 缺失仍为接口硬条件，必须与非法动作语法分别计数。引文缺失/非逐字摘要不是硬条件。

目标重评估追加通用句子说明置信度低并请模型依据公开信息判断，仍无候选目标/动作。目标 INVALID/COMPLETED 但模型沿用旧描述同样触发一次重评估，而非强制替换动作。保留原 action/reasoning/goal_description/goal_evidence schema 与 system prompt 基础模板、STM5。

## 正式实验

- 三游戏 remnant/mark/metropolis，每个 seed42、43、44 各一次，共 **9 局**，本地最多 9 并行，不超过用户授权的 12。
- 每局最多 300 环境动作，原生 done 提前终止。只运行 AGC-v2，既有 Stage18 与 Stage24 全部复用，无失败重采样。
- seed42 使用 Stage24 保存的精确初始世界，逐游戏与旧 Stage18 对照匹配；43/44 使用相同原引擎的独立重置，无人为选择初态。模型响应无可强制的服务端随机种子，三局同时包含环境种子和模型采样变化；单独展示 seed42 配对结果与三种子均值，不能把旧基线单 seed 与新三 seed 当成严格等样本配对。
- 相同 deepseek-flash、temperature 0.7、top_p 0.8、presence_penalty 1.5、thinking disabled、JSON、输出 768；相同引擎提交 248430692a9d4a61d38c6c03ab2126287faaf450、评分脚本。最多 2700 环境动作、13500 逻辑模型请求是理论上限，不是调用目标。缓存、逐请求费用和未知计费暂停机制复用 Stage24。
- 同样为 300 步研究配置，不标作正式 500 步榜单结果。Stage24 对照同时保留原始首跑和授权续跑口径，主要比较最终 1/11/4，不能隐去首跑 0/8/4。

## 指标与可归因范围

输出逐局官方 Main Quest、Supplementary、第一章/全主线、实际动作、终止；均值/范围/标准差仅描述三次采样，不计算显著性。

目标指标：连续同文本目标平均长度、全部 confidence 曲线、目标登记替换数（含正常教程切换）、低置信度触发的重评估数、实际替换时旧置信度、INVALID/COMPLETED 事件数。分别报告所有替换和低置信度后替换，不能将教程切换称为过度 reset。

reset 后成功率预定义为替换后到下一次替换之前且最多 20 个实际动作内获得≥1 官方主线奖励的比例；另报是否出现目标相关公开进展、是否达到字面子目标完成。正式试验内剩余不足 20 步的窗口需标注右删失并补充分母完整窗口结果；不是 reset 的因果效应。评分仅供离线分析，不反馈控制器。

动作指标：原生 invalid 数、模型语法拒绝数、缺字段数、同上下文连续失败拒绝数、action retry 请求数、硬拒绝终止数、最长连续同动作失败、wait/相邻重复比例、模型请求/token/费用。原生 invalid=0 可能来自提前终止或过滤，不单独作为可靠性改善证明。

进展指标：首次新公开状态的动作编号、公开新状态数、目标相关进展、字面 COMPLETED 数。长时间无 progress 比例预定义为完整 8 动作窗口内 informative 总和为 0 的结束动作数/实际动作数，并补充≥8 步连续无主线增量区段占比；相关性与新颖性均不等同于真实任务推进。沿用 Stage24 的共同 stale/停滞指标以便对比，并报告其多动作循环漏检。

先验判定：SUCCESSFUL_WORKFLOW_IMPROVEMENT 要求 mark 三局主线均值≥11 且至少 2/3 第一章完成；remnant 均值>1 且 3 局均不因动作语法/重复失败硬拒绝终止；metropolis 均值≥7 且至少 2/3 第一章完成。PARTIAL_IMPROVEMENT 为未同时满足前述条件但至少一个游戏相对 Stage24 主线均值增加≥1，或 remnant 三局均不因动作可靠性硬条件终止且其均值≥1。其他为 NO_FURTHER_GAIN。该操作化不具有显著性含义，不能证明新模块分别有效。

500 步建议只依据本轮证据提出，不自动启动新预算实验。只有三游戏无接口/语法提前终止、满足 SUCCESSFUL_WORKFLOW_IMPROVEMENT 且没有明显长循环主导尾段时才建议进入正式评测；否则先定位机制，不用更长预算掩盖故障。所有代码/协议先冻结，结果和离线分析后提交，记录全部费用和文件增删。
