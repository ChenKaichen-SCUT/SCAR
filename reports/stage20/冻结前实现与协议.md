# SCAR20 冻结前实现与协议

基于 `4de59f389af67cda9201b5256d150470622e5519`，全部新增代码位于 `scar_stage20/`，保留 Stage10–19 原代码、数据、模型请求及结果。沿用用户的本地执行要求，12 个独立任务进程；只运行 SCAR20 × 原 Stage17 的 24 题，不重跑历史方法、失败任务或消融。

## 变更

模型 JSON 六字段：`type, target, entry, evidence_ids, direction, uncertainty`。完成条件由控制器生成。接口层只处理 JSON/类型，证据引用与行动有效性由独立语义检查处理。模型仍为 DeepSeek Flash，temperature=0.7、thinking disabled、768 输出 token；保留已验证的供应商 `json_object` 输出约束，不假称支持未验证的供应商严格 Schema。

只允许单层代码围栏、无冲突字段别名、忽略冗余 completion、非空 uncertainty 字符串包装为列表。禁止补引号、猜对象名/ID/理由。JSON 重复键和别名冲突直接拒绝。连续三次响应不可用时记录费用并回退，不伪造成功响应。

公开证据用内容哈希 ID，包含原始结构化值、公开来源、观察时刻、首次入库时刻。提示最多64条／14,000字符证据，完整证据与历史请求持久保存；这比 Stage19 的48条／6,000字符大，必须计入实际 token 成本。提示快照深拷贝，避免 Stage19 的次级日志引用变动。模型猜测不写入 P1。

控制器保留 FIFO、三值公开判断、P1、100步 P3、Stage18 名义需求限量收取及原批量规则。已经持有的中间物不再为旧区域前提无目的搬迁；无法执行 FIFO 时只递归展开当前未完成依赖。已接受材料、前提制作和查找意图独立持久保存，查找不会因到达候选地点就成功；有阻塞/恢复/取消/完成日志。P3 的行动如果正好继续同一材料意图，则保留该意图；真实最终任务进展仍可收尾。

停滞状态机：EXECUTE → BLOCKED → PLAN/REPLAN → EXECUTE/EXPLORE → STALLED。公开资源、配方、路线、检查记录、守卫及即时风险构成上下文，步号变化本身不重置次数。每个相同上下文最多2个逻辑请求、每次动作选择最多2个、每局最多24个，每逻辑请求最多3次付费尝试；接受意图最多12步，探索意图最多6步，继承探索总上限18，前提递归深度8，挂起意图最多恢复2次。未尝试的公开合法入口可走有界探索；耗尽入口和重规划后 `method_stalled`，不产生无目的 wait。

`method_stalled` 同样计入24题失败分母，不能当作效率改进。风险检查与负面后果记忆不同；前者保留，后者不恢复。无任务专用路线/物品规则、无引擎修改、无名义配方与真实批量一致性修复。

## 零API验收与历史接口迁移边界

先通过全部单元测试、原12个成功任务关键动作、两处历史停滞短分支、JSON恢复与付费请求缓存验证，再冻结代码及测试数据的哈希。72条旧异常和69条旧证据拒绝逐条保留证据。旧响应没有新版 ID，因此历史迁移明确分两层：严格解析原文；将已命名入口确定性绑定到确实公开的记录，再跑新 Schema 与决策检查。旧引文不升格为事实，不声称原模型实际给出了这些 ID。不可解析的引号错误不修复。反例验证未来/不存在/不相关证据、虚构对象和不可达入口；合法探索只意味着允许有界验证，不能据此证明对任务有用。

## 正式协议

保持 `results/stage17/tasks.json` 的24题、物理种子、公开教程、环境版本与目标。每局最多100个真实动作，成功要求本任务制作目标且实际持有；教程不计入行动预算。全局新增费用上限3美元、每局0.25美元，以共享 SQLite 预留防止12进程超支。费用估计和重试风险见 `budget_estimate.json`；所有实际请求和失败响应均计费。

正式开始前创建唯一冻结提交；正式成绩出现后不改策略、不选择性重跑。全部任务结束后本地原生回放、独立无网络核验、离线统计和中文报告，上传自研代码与结果，不上传下载引擎、虚拟环境、密钥或私有二进制快照。完成即停止，不启动后续版本。
