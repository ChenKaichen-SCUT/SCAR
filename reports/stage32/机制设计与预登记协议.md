# Stage32 SAER 机制设计与预登记协议

依据工作区《指引32.md》。基线提交 `60311467be7245637abb7392e8c7b82686c9530a`。本协议及执行代码在新增模型调用前冻结；离线结果出来后不修改机制，也不按在线效果重采样。

## 实现边界

在原 Stage25 AGC-v2 上添加 SAER，不经过 REC 的需求推断、约束检查或风险停止。原系统提示、动作接口、JSON 决策字段、模型、五条 STM、AGC-v2 语法修复与目标置信度工作流保留。SAER 没有新增动作黑名单、替代动作、路径规划或任务专属规则。

TaskState 仅记最近 32 个公开执行转移，在模型输入中提供最多 8 条与当前/候选目标或同一动作相关的记录。摘要包含当前公开库存、装备、容器可见内容、地点、环境变化、已知失败及控制器标记的完成条件。unknown 不补零；不推断隐藏容量，不递归推导配方，也不把“取得成品”绑定为“制作成品”。原生接受与控制器完成标签不证明条件持续成立。该有限任务历史是机制的一部分，不能把试验称为纯增加一个反思句子。

每次原生决策调用：候选 → 一次后果预测 → 一次最终决策。候选输入是原 AGC 用户提示加公开任务摘要。预测只使用同一公开上下文与候选，输出 predicted_effect、goal_risk、reason；medium/high 标记 warning，low 不标记。最终模型看到候选、预测与其不确定性，风险再高也可保持候选。候选语法/目标字段已经不合原生格式时直接交回 AGC 原生修复，以节省无意义预测。预测 JSON 不合格式不重试、不禁止动作，最终决策按原证据继续。

最终动作仍经过原有 AGC-v2 检查；其原有三次语法修复/一次置信度复核可重复触发上述流程。这个继承机制可能早停或改变合理提案，必须单列；SAER 自己没有风险重审循环或风险耗尽终止。预测与最终决策均使用原模型及参数，不另加高能力模型。原始请求、三阶段角色、风险、所有候选/最终提案、控制器及任务摘要全部保存。

## 第一阶段：离线候选诊断

使用 Stage31 三条 REC 轨迹的全部 70 次已执行环境拒绝、全部 2 次移出物品后可见性丢失，以及终止状态下 5 个不同的合法候选（按状态、动作、显式目标去重；保留重复来源索引）。一个原生语法非法的终止提案不作为合法路径样本，原文和排除原因保留。共 77 个样本、75 个物理状态、三个相关母轨迹；不是 77 个独立任务。启动前覆盖核查补入这两次已执行条件丢失，避免只用被拒动作评价资源保持；此时新增 API 调用为 0。

候选复用原付费响应，不重新采样。移除原输入尾部 REC 摘要/拒绝意见，保留原 AGC 输入链，加入本轮从公开前缀重建的 TaskState。只新调用一次预测与一次最终选择，计划 154 请求。本轮最终判断是在新提示下的模型采样，原候选是在 REC 提示下产生的；因此是固定候选诊断，不是完整 SAER 在线性能或无偏反思因果效应。

所有候选与最终合法动作都在完全相同状态/RNG 下原生单步验证。对于 seed42/44 的终止状态，另接原轨迹最后一个被拒的取物动作，检验局部恢复路径；这个诊断后续动作不进入任何模型输入，也不用于在线动作选择。最终格式无效计为无效结果，不免费重做。原拒绝动作、候选反馈与未来信息不泄漏到预测输入；已有历史拒绝只在真实公开前缀中可用。

指标：候选改变、warning、原生接受/拒绝、同样重复失败、照明/库存改变、合法候选是否保持、候选后已验证两步恢复路径是否保持。移出资源不自动叫销毁，接受不自动叫任务进展。没有完整损害真值时不虚构“错误丢弃减少率”。离线全部结果和负例先保存、汇总，再启动在线阶段；不按结果调参。

## 第二阶段：remnant 在线配对

种子 42、43、44，各运行一个 SAER 原始初始状态到最多 300 环境动作的轨迹。复用 Stage25 seed42、Stage31 续完的 seed43/44 AGC-v2 完整轨迹，共 900 历史动作、970 历史请求；不重新运行对照。只启动三条新在线轨迹，不运行 mark/metropolis。

模型沿用冻结的 deepseek-flash 参数和计价配置。模型随机采样不能与历史对照严格配对，服务运行时间不同。环境初始状态、原生动作上限、评分、第一章完成判定完全相同。决策耗尽/传输异常保留原局，不因失败重开；仅精确缓存支持基础设施恢复。未知计费停止，不能盲目重发。

## 指标与归因

沿用 Stage31 公开拒绝、同地点同动作重复失败、明确前置条件重复拒绝、回取循环、可见→黑暗、移出物品后变暗、新区域、wait、主线/章节/恢复等口径，报告每局、每 100 实际动作及配对共同执行窗口。REC 的资源风险抽取只作事后诊断，不能当任务损害真值或进入 SAER。

反思效果区分全部预测和最终实际执行的最后一次预测，避免把原生修复/置信度复核重复计成多个环境收益。报告 warning 后动作改变比例、同状态候选/最终原生可行性、实际新公开状态、资源/区域变化及奖励。保持高风险候选并执行是允许行为，不算控制器错误。最终选 wait 可能增加谨慎，必须结合新状态与任务推进审计。

所有轨迹精确保存响应回放，核对上下文、动作、状态、奖励、TaskState 与最终记忆。原生候选分支检验只支撑局部动作差异，不能外推长程因果。公开摘要、额外采样和预测同时变化，缺少等调用预算对照，不声称反思单模块因果或已排除记忆/规划问题。

## 冻结前描述性判定

- PROGRESS_AND_RELIABILITY_SUPPORT：至少 2/3 对主线或第一章提高、无该终点下降；共同窗口至少 2/3 对拒绝减少且合计下降至少 10%；没有比对照多的方法早停。
- LOCAL_RELIABILITY_ONLY：满足上述错误减少、无终点下降且无额外早停，但未达到稳定推进标准。只说明局部可靠性证据，不能直接扩大三游戏。
- REGRESSION_OR_BLOCKING：出现主线/章节退步或额外方法早停，须重点审计过度谨慎、错误预测和继承控制器；不因其他计数改善掩盖。
- NO_CLEAR_SUPPORT：其余或混合、不确定结果。阈值仅作小样本行动标准，非显著性检验；所有三个样本和全部离线样本保留。

本轮只实现并测试所述 SAER，不根据观察增加新机制。无论结果如何，三游戏扩展仅给建议，不自动执行。
