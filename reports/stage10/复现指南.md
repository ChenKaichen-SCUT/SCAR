# Stage 10 复现指南

使用Python3.12、仓库原依赖和上游AgentOdyssey提交 `248430692a9d4a61d38c6c03ab2126287faaf450`。依赖安装沿用仓库README；下载的引擎、模型及缓存不随本轮发布。以下在SCAR仓库根目录运行，所有重算请使用独立checkout，避免覆盖原始证据。

## 已发布闭环的零 API 重放

```bash
export PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export AGENTODYSSEY_ROOT=/path/to/agentodyssey
python -m pytest -q tests/test_stage10.py tests/test_stage9.py tests/test_stage8.py tests/test_stage7.py tests/test_unknown17.py tests/test_sequence.py
python -m scar_stage10.reproduce --runtime /tmp/scar10-replay --replay-saved
python -m scar_stage10.diagnostic_replay --output /tmp/scar10-knowledge-replay.json
python -m scar_stage10.interpret
python -m scar_stage10.report
python -m scar_stage10.publication
```

单测88项。reproduce核对冻结源码/数据，恢复10个已生成初态，逐动作重放全部40局并比较1244个状态哈希、拒绝和目标结果，不访问模型。仅使用本项目生成的可信快照（已去除模型客户端与凭据）；快照依赖相同引擎版本和Python。默认没有付费调用，亦不创建其他游戏环境。

interpret（无runtime时）直接从已发布请求与轨迹重算模型、费用、边界、风险与局部资源比较，保留已发布的原生容量核验。report生成三份统计/逐例/完整动作链文档；静态实验报告和research_judgment记录原始实验解释，不自动推广到新模型运行。publication检查原始这批数据，不是任意新结果的成功率验收器。

历史门槛和暂存组件压力检查可在独立副本重做：

```bash
python -m scar_stage10.offline --runtime /tmp/scar10-offline
python -m scar_stage10.storage_checks --runtime /tmp/scar10-storage
```

offline只访问原10个Robot历史状态；6个关键中间态每配置使用固定wait基础提案，控制器自主决定续动作，每条物理分支重放两次。storage_checks是组件压力夹具：填满一个旧初态背包、增加一个原生空容器实例，显式给组件收集/取回需求；失效变体在离开时清空容器。它不是新family或自主整局成绩。两者均零API。

## 有原始runtime时重新分析

```bash
python -m scar_stage10.finish --runtime /root/scar_workspace/runtime_stage10 --workers 8
python -m scar_stage10.interpret --runtime /root/scar_workspace/runtime_stage10
python -m scar_stage10.knowledge_checks --runtime /root/scar_workspace/runtime_stage10
python -m scar_stage10.report
```

finish只处理已经全部结束的40局，顺序执行中止审计、原生资源/批量/同状态反事实、统计、物理重放与账本核对，不请求模型。interpret的runtime参数补算所有动作前的真实容量覆盖；knowledge_checks根据明确的事后筛选规则生成两步知识桥接诊断，使用隐藏目录的评测器不能冒充政策。发布的7份诊断快照和14个分支可由 `diagnostic_replay` 独立重放；实际后缀记录在 knowledge_counterfactuals.json，逐步物理哈希、公开观察、拒绝与目标结果必须一致，每分支执行两次。本轮独立本地结果见 knowledge_portable_replay.json。

服务端原始runtime的每步快照与记忆均保留；GitHub发布的是10个压缩初态、完整40局轨迹/请求、重放状态摘要、必要诊断快照及分析，足以进行默认40局零API重放，无需下载整套服务器runtime。

## 如需独立重新调用模型

原40局已经完成，无需重跑。使用独立checkout、全新空runtime和自己的密钥文件，只有显式下列参数会付费：

```bash
python -m scar_stage10.reproduce --runtime /path/to/fresh-scar10 --run-closed-loop --key /private/keyfile --workers 12
python -m scar_stage10.finish --runtime /path/to/fresh-scar10 --workers 8
```

协议固定10题×4配置、每局40动作、原一个物理种子、全局$3、单局$0.20；已有runs目录拒绝付费重跑。temperature=0.7和供应商服务使独立模型轨迹、缓存与成绩可能不同。不得用新运行替换原结果或直接套用静态报告结论。没有旧六个服务器账本的独立机器只核对本批账本，旧累计采用发布口径并在verification中标识来源。
