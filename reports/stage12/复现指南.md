# Stage 12 复现指南

本轮发布的是阶段 A 全部诊断与阶段 B 未运行记录。使用 Python 3.12、仓库已有依赖及 AgentOdyssey 提交 `248430692a9d4a61d38c6c03ab2126287faaf450`；引擎安装沿用仓库 README，不随本轮上传。命令从 SCAR 仓库根目录执行；重算会写结果时，请使用独立 checkout，保留原证据。

## 零 API 复核

```bash
export PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export AGENTODYSSEY_ROOT=/path/to/agentodyssey
python -m pytest -q tests/test_stage12.py tests/test_stage11.py tests/test_stage10.py tests/test_stage9.py tests/test_stage8.py tests/test_stage7.py tests/test_unknown17.py tests/test_sequence.py
python -m scar_stage12.reproduce --output /tmp/scar12-portable.json --workers 8
python -m scar_stage12.interpret
python -m scar_stage12.report
python -m scar_stage12.publication
```

共 140 项测试。`reproduce` 首先核验冻结代码、数据和受保护历史文件，恢复 50 个已发布状态，然后对全部 363 个已记录候选按原公开执行程序各运行两次，比较完整反馈、知识、资源消耗、停止原因及物理状态哈希；每遍 665 个动作，不调用任何模型。只加载本项目发布的可信快照，需要相同 Python 和引擎版本。新独立记录写到指定 output，不会替换已经发布的 `local_portable_replay.json`。

`interpret` 只读取保存的请求和分支，核对提示、请求时间、模型、token 和费用，生成事后行为分类；不改变冻结的继续门槛。`report` 重建 50 个完整状态证据页及总索引，不自动改写人工研究结论。`publication` 检查原始发布批次的一致性、冻结完整性、候选覆盖、零 API 重放、未运行 B 的状态及敏感信息，不访问模型或引擎。

## 从保存的判断重新评价与统计

在独立副本中运行：

```bash
python -m scar_stage12.evaluate --runtime /tmp/scar12-reanalysis --workers 8
python -m scar_stage12.analyze
python -m scar_stage12.interpret
python -m scar_stage12.report
```

`evaluate` 从 `states.json`、可信状态快照和 `judgments.json` 恢复全部公开候选及 J2 自由动作，所有选择先确定，再执行原生审计。真实依赖、精确消耗和世界状态只用于评价；候选执行函数只接收公开控制器和反馈。`analyze` 严格按冻结条件重算同状态配对、family bootstrap、覆盖与 GO/NO-GO。没有隐藏配方指定的后缀。

## 原始抽样与冻结过程

原过程入口为：

```bash
python -m scar_stage12.prepare configure
python -m scar_stage12.prepare select
python -m scar_stage12.prepare snapshots --runtime /tmp/scar12-prepare
python -m scar_stage12.evaluate --preflight
python -m scar_stage12.prepare freeze
```

这些命令是原始建集流程说明，**不要在当前发布目录直接执行**：configure 要求基准 HEAD 为 `1bdf872` 且不存在冻结文件；freeze 还要求测试 XML 和预检已通过。源池只用 Stage 10 S1、Stage 11 E0/E1。固定每题 5 个槽、来源和索引偏好，不按候选真实收益抽样；状态先生成、哈希及提示冻结后，才允许新增模型调用。已发布状态足以复核，无需重建或重新选择。

## 模型请求入口与实验停止点

原阶段 A 由以下入口在服务器执行，现已完成；该命令会产生费用，不属于默认复现：

```bash
python -m scar_stage12.run --runtime /path/to/new-empty-runtime --key /private/keyfile --workers 8
```

运行前强制核验冻结文件；总计 100 次主判断和 20 次指定稳定性判断。全局 $0.75、每查询 $0.04，最多沿用既有提供器 3 次传输/格式尝试；语义不佳不重采样。已有 `launched.json` 时拒绝重新启动，不从多次答案中挑最好结果。正式独立模型运行的结果可能不同，必须在另一个 checkout/runtime 保存，不能替换本批原始判断或套用静态报告结论。

本批门槛为 NO-GO，**没有阶段 B 付费运行入口或在线 B3 实现**。阶段 A 的有界候选执行工具不能冒充 B3，也不能把已保存分支成功当作闭环成功率。未来若另行研究其他提示或执行器，应作为新的冻结实验，不能修改本批定义。
