# Stage 11 源码审计与预先设计

基点为 Stage10 `c1cf74814abf84387723fe5e342b29a1b7042168`。正式模型运行前完成本审计；只改独立Stage11文件，保留全部1833个既有跟踪文件。

## 继承关系与变更边界

逐方法审计 `scar_stage10/controller.py`、`scar_unknown17_stage7/controller.py`、`scar_sequence/planner.py`，并追溯 `scar_unknown17/controller.py`、公开资源表和PublicFacts。

S1 是 ResourceController → Stage7Controller(C1) → SimpleController → FIFO Controller。C1只开启retry_context_fix；Stage7其他探索切换、资源保护/缩量机制都关闭。S1的三值判断、失败条件变化重试、基础进展保护和受阻替代动作保留。其父类定向探索已有“先检查可见对象，再试做已知前向配方，检查新产物”的逻辑；问题不等于原算法完全没有这些能力。

FIFO在未知队首依赖处进入探索，探索先处理广泛可见未检查对象；现有数量需求可能来自公开成功样本或失败后的有界quota。新代码不修改该批量规则，不启用Stage7 D/F1缩量，也不扩展GPAR。`GoalController._fifo is ResourceController._fifo`、`_batch_action`相同由自动测试确认。

| 配置 | 控制器 | Prompt |
| --- | --- | --- |
| E0 | 直接原S1类，非复制改写 | 原Prompt |
| E1 | 同E0 | 原Prompt加固定简短提醒 |
| E2 | S1子类，只调整公开目标相关探索排序 | 同E0 |
| E3 | S1子类，只优先已知必要执行并同步FIFO | 同E0 |
| E4 | 两个优先级开关同时启用 | 同E0 |

三个显式优先级配置都将受公开条件支持的基础最终目标动作置于高优先级，避免新排序盖掉直接完成机会。这项共同优先级也属于它们相对E0的变化，不能把全部收益只归因于前向探索。机会收集、暂存和GPAR均为False。E0/E1直接原类，在给定相同提案时应逐状态完全一致。

## 公开依据与有限规则

目标视图通过最多64个节点的普通工作表遍历公开配方原料名称，按当前未满足父节点激活必要输入。它不是搜索树，也没有隐藏配方边。原有FIFO顺序保留，E3/E4只追加新公开必要输入、移除已满足或已不属于当前必要链的节点；原批量函数和公开资源表不变。

节点状态为COMPLETE、READY、BLOCKED、UNKNOWN。READY只指公开已知材料下界及已知站点支持，实际数量仍可能UNKNOWN；未知站点可进行受原重试条件限制的实际尝试，不冒充原生合法保证。原生真值只在独立评价器中判定。

探索按五级公开依据排序：当前明确未解的目标依赖、已确认的目标中间物、可能桥接未知依赖的已知/真实产物、其他由公开物料和FIFO支持的候选、原广泛探索。每个列表最多32个候选。相同级别按是否可就地推进和公开名称确定次序；没有物品名称特例或目标字符串的专门匹配。新产物标记来自真实制作反馈及既有公共生产历史。

可能的桥接产物只记录 `unknown_downstream_connection=True`，不加入目标依赖边。试做仅用已公开配方及已观察可获得原料，沿用4次试做和18探索动作上限；不会为了试做消耗持有的最终目标或公开必要且无余量的已完成中间物。取得材料仍调用S1原 `_acquire`，没有S2整批机会囤积规则，也没有S3位置缓存。

及时执行只在已公开连接的必要节点上工作，先考虑现成产物，再考虑原批量制作、缺料获取和新必要产物检查；不会因缺未知配方而猜测隐藏前置。合法有用的基础提案可以保留。历史试图采样出的动作绝不通过family ID送入控制器。

## 预先评价与成本约束

正式只运行原10题×5配置、每局40步、一个原物理种子。E0真实重跑，E1只改冻结提醒。首次请求集成检查必须确认E0/E2/E3/E4字节级相同，E1恰好多固定段落。无额外模型、规划器或多智能体。

任务完成是第一层结果，另外分别评价新规则发现、相关探索、真实中间物生产、3动作内检查、公开已知且原生可行的必要子目标当步/3动作内执行、发现到有效制作延迟。最后三动作无法完整观察的窗口单列删失；未转化配方不从报告中删除。无公开关联或非真值依赖物品的探索不自动等于无用探索。

E2/E3对E0、E4分别对E0/E2/E3做同状态同模型提案的局部开关反事实，两物理分支重复重放。E1的Prompt收益只比较真实闭环及提案日志，不额外调用模型构造伪配对。整局不同轨迹不能自动归因于单个模块，成绩相近时必须承认额外价值未证实。

固定计价沿用历史协议，50局满40步按Stage10实际每动作费用估计约$1.081564408；设全局$4、单局$0.20硬上限。正式前冻结策略、提示、任务、协议和测试；之后不按成绩修改算法、补跑失败局、延长步数或增加任务/种子。
