# Stage 11 复现指南

使用 Python 3.12、仓库已有依赖以及 AgentOdyssey 提交 `248430692a9d4a61d38c6c03ab2126287faaf450`。依赖安装沿用仓库 README；下载引擎、模型、私有 runtime 和凭据均不随本轮发布。以下命令在 SCAR 仓库根目录执行。需要重算结果时使用独立 checkout，保留原始发布证据。

## 默认零 API 检查与重放

```bash
export PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export AGENTODYSSEY_ROOT=/path/to/agentodyssey
python -m pytest -q tests/test_stage11.py tests/test_stage10.py tests/test_stage9.py tests/test_stage8.py tests/test_stage7.py tests/test_unknown17.py tests/test_sequence.py
python -m scar_stage11.reproduce --runtime /tmp/scar11-replay --replay-saved
python -m scar_stage11.interpret
python -m scar_stage11.report
python -m scar_stage11.publication
```

测试共 118 项。`reproduce` 检查冻结源码/数据、解压 10 个已生成初态，逐动作重放全部 50 局，比较 1,593 个物理状态哈希、拒绝和目标结果；不会请求模型。每次结果写入指定 runtime 的 `portable_replay.json`。已发布的 `local_portable_replay.json` 是本轮独立本地验证记录；上述命令产生新的独立记录，不会自动替换它。

仅加载本项目发布的可信快照，使用相同 Python 和引擎版本。快照是实验生成的状态，已去除模型客户端与凭据；引擎本体不在提交中。`--replay-saved` 必须显式提供，否则 `reproduce` 默认只核验初态，不应将其 0 局结果当作完整重放。

`interpret` 从已发布轨迹/请求重算模型、缓存、格式重试、提示一致性、边界及公开风险审计；`report` 重建 3 份总表/行动链文件及 10 份完整证据页。静态中文实验报告和 `research_judgment.json` 是对原始批次的研究判断，不会自动改写成新模型运行的结论。`publication` 验证这批发布数据的一致性、冻结哈希、受保护历史、结果计费、文件范围和凭据泄漏，不调用模型或引擎。

## 零 API 历史机制测试

在独立 checkout 中执行：

```bash
python -m scar_stage11.offline --runtime /tmp/scar11-offline
```

此入口从已发布的 Stage 10 轨迹、初态和知识缺口快照恢复原 10 题历史状态，并读取 Stage 8 原任务的 6 个关键中间态；不读取 Stage 8 新增 family，也不构造新任务。复核 622 次 E0/E1 参考一致性、6,220 次历史决策及 154 个真实引擎单步配对状态；生成 18 个历史状态 × E0/E2/E3/E4 的 72 条控制器自主续行，每条重放两次。续行使用固定 wait 基础提案和剩余 40 步窗口，没有评测器正确动作后缀。E1 在固定 wait、无模型请求时与 E0 等价，只用于代码参考，不代表提示对照的正式效果。

`offline` 会重写 `results/stage11` 下历史测试结果和状态文件，因此务必在副本中操作。历史前提下的 10/18 或 6/18 不属于正式初态恢复率。

## 有服务端原始 runtime 时重新分析

```bash
python -m scar_stage11.finish --runtime /root/scar_workspace/runtime_stage11 --workers 8
python -m scar_stage11.interpret
python -m scar_stage11.report
```

`finish` 要求 50 局均已结束，顺序执行中止审计、原生资源/制作批量/基础提案/开关反事实、统计、物理重放及账本核对，全部零 API。原始 runtime 保存每步快照和记忆。GitHub 发布初态、完整轨迹、请求和逐步重放摘要，足以执行默认的 50 局物理重放，无需搬运整个 runtime。历史自主续行的 18 个状态及控制器记忆也已经发布。

## 另行授权的独立付费复现实验

本轮 50 局已全部完成，不需要再次调用模型。若另行进行独立实验，使用全新 checkout、空 runtime 和自己的密钥文件，只有显式以下参数才会付费：

```bash
python -m scar_stage11.reproduce --runtime /path/to/fresh-scar11 --run-closed-loop --key /private/keyfile --workers 12
python -m scar_stage11.finish --runtime /path/to/fresh-scar11 --workers 8
```

协议为原 10 题 × 5 配置、每局 40 动作、原物理种子，全局 $4、单局 $0.20；已有非空 runs 的 runtime 拒绝付费重跑。固定温度 0.7 和远端模型服务使新轨迹、缓存费用与成绩可能变化，不能替换原证据或直接套用原研究结论。没有历史服务端账本的机器只核对新批次账本，历史累计采用发布值并在 verification 中说明来源。
