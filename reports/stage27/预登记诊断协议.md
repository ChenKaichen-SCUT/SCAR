# Stage27：State Grounding Diagnosis 预登记

本阶段依据用户在会话中给出的 Stage27 全文执行。研究问题是失败后的状态缺口理解与公开前置条件维护；不实现下一阶段机制。

## 冻结与样本

- 生产 Agent、基础 prompt、deepseek-flash 及其采样参数、环境、Stage25/26 原始轨迹全部冻结。只新增 `scar_stage27` 离线诊断脚本与材料，不导入生产 Agent。
- 穷举母轨迹 34 次与 Stage26 十个 Oracle 分支 302 次公开拒绝，共 336 次；不按模型回答筛选。独立母轨迹数始终为 1，不把 336 个检查点视为独立任务。
- 全部 336 次做失败理解测试。两次第 300 步拒绝不做下一动作回放；其余 334 个检查点做 A/B 成对动作测试。
- 全部原生状态先用保存响应无网络重建，再核验下一原始动作。Agent 内部过滤的语法/元数据错误另存，不混入环境拒绝分母。

## 实验一

每条记录一次新模型请求，提供拒绝前 observation、目标、手持物、位置、最近五动作以及本次真实反馈和拒绝后 observation。要求原因、缺失条件、恢复优先项、目标有效性四个自由文本字段，不给失败类别选项或隐藏答案。诊断 prompt 是测试题，生产 prompt 未改。

公开反馈确定 gold 失败类型。人工结合可重算规则检查原因、恢复条件、是否编造额外规则。四级评价：Correct=明确命中公开缺口且恢复条件相容；Partial=原因部分正确但缺少/错误恢复条件；Wrong=与公开拒绝矛盾或将其他因素当成主因；No=无法作答/不可解析。原因不明确的环境反馈应承认未知。给出可能性不算擅自断言。单独保留原因与恢复子评分，不能只靠关键词宣布完整正确。逐样本标签和证据保存；不调用模型裁判。

## 实验二

- 测试时点为失败之后。A 首次请求与已保存的下一决策第一个请求逐字相同；B 在相同请求末尾追加公开状态 JSON，系统 prompt 和输出 schema 一致。通过原有 `goal_description` 和理由分析是否保留目标，不另增输出字段。
- A/B 都重新采样一次。历史回答只作描述，不把经过失败筛选的旧动作作为唯一 A。奇偶交替提交 A/B 顺序，每组最多 12 并行；无模型裁判，无质量重采样。
- B 结构化字段 inventory/known_tools/known_requirements/failed_actions/blocked_actions/current_location 来自该分支截至检查点的公开文本；每条规则/工具记录保留原始引文与步号。历史库存与失败不可当成当前事实；容器内容标明可能过期。不得访问隐藏世界定义生成提示。
- B 汇总全部过去公开反馈，A 维持原 STM 输入。因此这是历史检索/维护加结构化呈现的联合干预，不能隔离纯格式效应，也不是新算法成绩。
- 一次原始提案用原公开动作语法核验后直接送入相同原生状态副本；不经过 AGC 仲裁，不修复、不重采样。非法 JSON/语法计为不可用决策并停止该探针。原生接受、拒绝、死亡、公开信息变化、库存/位置变化和主线奖励全部保存。隐藏状态只用于同状态核验和评分，不进入 prompt。
- 全部 334 对测一步。母轨迹 34 对预定最多三步：在同一基础输入后追加自身真实提案与环境反馈，B 另更新公开状态；不额外提示目标或动作。第三步仍不超过绝对 300 步。短链是独立离线探针，不调用或改动 Agent 的记忆/控制器。
- 一步相同初始状态与 RNG；后续真实模型随机采样会分叉。没有可控供应商种子，不将长链差异等同于严格模块因果效应。

## 指标与解释边界

主要指标为原生接受比例（不可解析/非法动作也计入分母）、A/B 配对四格表、重复已失败动作再次拒绝、有效新公开信息、主线奖励。分母分别报告母轨迹、十分支和总样本；同时给出失败类型分层，不选取有利样本。

次要指标包括新区域/公开状态、资源变化、三步内再次拒绝/恢复与目标有效性审计。公开新信息（包括失败反馈、战斗事件）不自动视为任务推进；接受也不自动视为合理策略。目标语义是否有效需要公共证据，不能由目标字符串改变替代。

预登记描述阈值：实验一 Correct≥80% 表示此类显式反馈的解释能力普遍存在；Wrong+No≥50% 才支持普遍理解困难。B 原生接受绝对提升≥10个百分点且有非战斗信息/资源或任务进展一致证据，才称明显的短期决策改善。阈值是描述口径，不是显著性检验，也不用于调参。其余结果报告混合/不足，不强行塞入重叠的 A/B/C 叙述。

解释正确不证明在线前置条件维护正确；三步改善不证明长期任务完成改善；三步无提升不证明所有 State Grounding 方案无效。只有一个母任务、一个模型、一次新采样，不能断言普遍主要瓶颈。最终明确区分模型理解、信息保存/利用与长期执行策略证据。
