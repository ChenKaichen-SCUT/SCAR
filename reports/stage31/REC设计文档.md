# Stage31 Resource-grounded Execution Controller

REC 在 Stage25 AGC-v2 上增加公开状态追踪、当前制作需求对照和动作前的 ALLOW / RECONSIDER。代码在 `agents/rec_v1/`，原 AGC-v2、原模型、环境与评分代码不变。它没有规划器、搜索、递归配方展开、自动子目标或替换动作。

## 信息边界

仅读取已经收到的 observation、执行动作、公开反馈和模型显式 goal_description。隐藏状态只供实验保存、原生复放及事后探针使用，不进入 Tracker、提示或动作判定。没有游戏物品、地图或任务专属表；公开文本的语法解析是实现约定，不能把它称为零人工假设。

Tracker 记录公开持有/装备、地点、地面、邻接区域、已检查容器、公开工具说明、失败动作、已完成制作和历史条件丢失。黑暗或省略字段是 unknown，不是空库存；未知容器内容不补零。已观察容器的存放/取出更新计数，制作等可能消耗内容后将其数量降为未知。记录是公开观测的下界/最后观测，不是全知当前世界。

Requirement Tracker 只绑定模型已说出的制作目标或本次 craft 提案。优先识别明确 craft 数量和产品，其次同一目标的已有制作尝试，再次唯一公开配方产品名；没有唯一匹配就不强行绑定。只展开一层公开配方，不生成父子目标或资源路线。公开数量乘以明确尝试数量；未明确的总任务量保持未知。成功制作解除同一生产尝试的材料要求，避免持续保护已经消耗完的前置材料。工具/工作台条件仅来自公开检查与实际拒绝。

库存缺口只表示“公开持有量与配方的差”，不证明物品在全世界缺失或制作必然失败。环境可能允许利用地面材料，REC 不假装事先知道其取料规则。

## 四类约束

1. **资源保有风险**：提案移出/消耗当前任务公开需要且公开持有的物品，数量不足以保留需求时要求重审。drop 可能仍可回收，不能称资源销毁；转存自己携带的容器不因材料重要就自动判销毁。
2. **相同公开状态下重复失败**：同动作曾被拒绝，且已追踪的完整可见状态及相关知识没有变化时要求重审。黑暗和已知内容未知的容器不适用。未追踪的隐藏条件/时间仍可能改变，因此这不是动作永远不可行的证明。
3. **经验条件丢失风险**：实际移出某持有物后，同地点的可见状态变成公开“too dark to see”，记录该关联；以后同地点再移出最后一件时重审。首次没有此经验时不拦截。只把可见/持有容器当可执行转存目的地；关联不等于已识别因果。
4. **已知设施离开风险**：当前目标公开需要某设施，已知材料持有量齐备，当前有该设施，而唯一匹配的曾访问目的地最后观测无该设施时重审。目的地可能变化，证据带历史不确定性。没有地图寻路或新目标推荐。

所有 RECONSIDER 都附公开证据和不确定性，不提供替代动作或新目标。LLM 可改变提案，也可依据现有证据改变显式目标；REC 不用旧目标硬锁定新目标。此设计也可能被目标改写绕过，必须报告实际行为。

## 调用与停止

每次模型请求在原 AGC-v2 用户提示后附 `REC public execution state`。原系统提示、JSON 输出字段、模型参数、五条 STM 和 AGC-v2 验证链保留。触发 REC 时附被拒提案及证据，让原模型重新输出。

每个环境决策最多新增两次 REC 重审；原 AGC-v2 的语法修复/置信度重审上限不变。仍触发约束就以 `agent_decision_exhausted` 结束原局，绝不填 wait 或替换动作。该早停是方法失败结果，不能因动作变少就宣称效率提高。只有最终被原 AGC-v2 接受的模型动作进入 STM 和环境。保存每个原始提案、约束、提示哈希、经过 AGC 的提案、最终动作、完整请求和逐步 Tracker 状态。

## 开发验证与已知边界

先使用全部 Stage29/30 的 20 条历史后缀检查（同一条母轨迹的 10 个检查点，两种提示条件）。初检 43 告警暴露 unknown 被误当不变及不可见容器照明预测问题；冻结前统一修正，原源码、43 条初检记录和统计保留于 `pre_freeze_review/`。最终 39 告警不作为独立测试集性能。没有按在线奖励改动规则。

11 项通用状态测试、三种子原生前两动作兼容性，以及脚本模型的重审/重审耗尽测试通过。历史原生回放 3,116 动作、3,439 上下文完全一致，另 57 个零 API 隔离探针。

识别不到间接目标、别名、多层依赖或未知配方时不会生成需求。没有完整容量、工具用途、战斗/时效模型。记录缺失的公开事实会漏检；追踪不到的状态变化也可能误报重复失败。风险提示不能证明禁止该动作对长期任务有益。在线比较同时改变公开状态可见性与动作重审，并非控制器拦截的独立消融。
