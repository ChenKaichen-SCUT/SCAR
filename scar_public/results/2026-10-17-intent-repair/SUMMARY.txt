Release decision
The V13 public-task/method audit stays enabled, but paid LLM method-review
enforcement is OFF by default (intent-mode=observe). The paired diagnostic did
not justify paying for it. Explicit enforce remains available for research.
The subsequent capacity/reachability pre-pruning is enabled in V13; older
methods remain unchanged. No full-manuscript claim or LaTeX change is made.

1. Early intent review and causal controls
Read public NPC imperatives as tentative current instructions. Replacing one
instruction does not prove completion. Separate terminal endpoint from upstream
production via observed numeric/qualitative dependency paths. Check raw proposals
before acquisition and check actual consuming commands after acquisition. Do not
review navigation/gathering merely because a resource_target was present.
Log raw proposal, revision, final command, task evidence and reserve calculation.
At most one extra review call per action, no repeated payment for an unchanged
review key, and no forced inspect/look loop when uncertainty remains unresolved.
Neither a category description nor material feasibility proves task completion.

2. Constraint-based search acceleration (after the paid diagnostic)
Before acquisition search, eliminate recipes exceeding an optimistic bound on
joint hand/container input capacity; then compute a relaxed closure of item
types at reachable known locations with known stations. If the target is absent
even in this relaxation, bypass acquisition expansion, preserving the existing
paid capacity-discovery fallback. Recompute on each query as public state changes.
This is a conditional impossibility result for this finite observed search model,
NOT an assertion that the real task is impossible. Proof and exact assumptions:
scar_public/experiments/acquisition_pruning_notes.txt.

No-API paired benchmark on every craft/resource-target query in the recorded V12
full_clock trajectories, 131 queries total. Both arms receive separate clones.
Seven CPU timing repetitions; these are NOT repeated game experiments.
Time includes cloning, compilation, relaxation and fallback, not just expansions.

game        queries  base nodes  pruned nodes  base median s  pruned median s
Mark            32         772           196       0.053778         0.049408
Metropolis      74       80016          4550       0.790797         0.260218
Remnant         25         150           141       0.063976         0.064327

Metropolis query batch: 3.04x faster, 94.31% fewer search states; about 0.53 seconds
absolute savings. Mark small improvement, Remnant essentially neutral/slightly
slower. This is NOT a 3x LLM-game speedup: provider latency dominates end-to-end.
All 131 semantic query outputs (excluding diagnostic search_nodes) and discovery
side effects agree; all 58 candidate plans are preserved. No claim that altered
search-count metadata cannot affect a future LLM sample. Independent unseen
worlds and final accelerated end-to-end game performance remain untested.

The proof connects the implemented precheck to safe pruning in its modeled
search graph. It does not establish a new general planning theorem or novelty
over established delete-relaxed reachability. Its contribution here is making
the existing joint-capacity reasoning actually save measured search work.
