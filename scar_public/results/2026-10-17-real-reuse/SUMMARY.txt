REAL GAME EVIDENCE REUSE AND ACQUISITION COST (2026-10-17)

RESULT AND SCOPE

Found a naturally recurring Metropolis craft context. In a real-engine replay
with a fixed actor proposal stream, one charged acquisition action prevents
three later failures; the two arms reach the same visible inventory/location/
equipment and quest score using 67 versus 64 actual environment actions. In a
separate free-running LLM continuation, persistent evidence reaches score 17
versus control 16 at the same absolute 300-action limit. Neither completes the
full task. This is one selected development scenario and one sample per LLM arm,
not independent benchmark superiority or a statistical causal-effect estimate.

DISCOVERY AND WHY THE PREVIOUS AUDIT MISSED IT

Public V6/V8 prefixes contain 67 craft proposals, 22 groundable. Matching the
existing guard without relaxing it finds one recurring recipe/context family:
Metropolis gavel_club. V8 steps 174,184,189,207,216,240,250 share the guard; V6
steps 163,173 also share it but do not provide an informative acquisition.
The prior audit covered only 11 selected planner queries. The agent's six-search
quota meant that later LLM craft proposals could bypass planning and continue
executing a contradicted method even though the evidence ledger existed.

The shared real acquisition at step 184 attempts craft 1 gavel_club at the
observed clerks_bench with two timber in hand and binding thread on the floor.
Failure excludes floor-accessible profiles, conditional on the declared family.
The hand limit is two while the recipe needs three total input units. Remaining
profiles were originally success-exempt for this local fragment; the failed
trial is not a claim of local milestone or global task completion. Equipment
changes and new family conditions still prevent reuse. No material is inserted
into the environment and no new random seed is chosen.

MINIMAL IMPLEMENTATION CHANGE

evidence_decision_v10 reviews actual proposed crafts even after expensive search
is exhausted. It asks for one bounded LLM revision only when all retained
profiles predict the same physically inert failure, while some unfiltered
profiles still predict success. Thus the prior real observation, rather than a
search failure or an already-obvious shortage, changes the decision. Review
uses the existing paired profiles and guards, not a new LLM classifier or planner.
A repeated invalid repair falls back to a charged station inspection; no such
fallback occurred in this LLM run. Exclusions are still model-relative, not a
global prohibition or proof of quest impossibility. Time advances on failures;
unmodeled temporal effects remain a limitation.

FROZEN PROPOSAL STREAM: ACTION ACCOUNTING

Real checkpoint: V8 Metropolis 0183; original proposals 184 through 250.
Both arms execute the same first acquisition. Control executes all proposals;
reuse skips only evidence-rejected redundant failures. Every other command,
including travel, material handling, inspections and failed actions, is charged.

                                    Control        Reuse
Environment actions                    67            64
Initial acquisition actions             1             1
Subsequent prevented failures           0             3
Initial / final quest score          10 / 12       10 / 12
Full task complete                     no            no

Prevented proposals: 189,207,216. Each was actually tried in an isolated clone
of the treatment's then-current real environment and failed without changing
visible physical state or score. The same three commands were also validated
at their original historical checkpoints. Final game time differs by 30 minutes;
visible equality does not prove equality of hidden state or future outcomes.

Actual between-arm saving is 3 actions, already including acquisition in both.
If the ENTIRE one-step acquisition is conservatively charged separately against
the three later avoided failures, net benefit is 2 actions. This second number
is separate amortization accounting, not an additional between-arm saving.
This test uses a frozen proposal stream, not autonomous LLM choices.

Every one of the nine vetoed proposals was subsequently executed in an isolated

not immediately advance the task. Preventing a failed craft does not by itself
construct a successful alternative method.

POST-HOC COMMON-PROGRESS DESCRIPTION

The highest score reached by both arms is 16. This threshold is a descriptive
post-hoc comparison, not the preregistered primary endpoint.

                                    Control        Reuse

Actions from before acquisition         113            69
New API requests to that transition     135            95

This run reaches the common progress level 44 actions earlier with reuse, with
the initial acquisition already included. The primary fixed-budget endpoint
is only a one-point advantage. Full-budget reuse incurs 22 more API requests and
about 74 more summed request seconds. Those additional requests include the
nine evidence revisions plus differences in other trajectory-dependent calls;
do not attribute all 22 to the review hook or claim overall API/time savings.

TOTAL COST, VALIDATION, AND REPRODUCTION

300 API requests in the two paid continuations, all 300 successful with usage
records; zero unknown-charge attempts. Sum under the provider's configured
peak-price formula: USD 0.857445444. This is an estimate, not a billing receipt.
Acquisition reused the historical public target and used one environment action;
its replay needed no new LLM call. The earlier V8 target decision had one API
request (configured estimate USD 0.002931168), already billed in the earlier run.
The table excludes that shared historical prefix cost. Allocating this old
request to both arms adds one request and the same amount to each and leaves
differences unchanged; it must not be charged again as a new request. See
shared_acquisition_api.json. There were 15
separate retained evaluator validation actions (3 treatment shadows, 3 historical
checks, 9 LLM veto checks), which are outside the measured agent trajectories.

63 server tests passed, including real-environment protocol tests. A local test
attempt had 61 passes and one missing-cloudpickle environment failure; the full
server environment resolved that dependency and passed all 63 after adding a
legacy-checkpoint test. Offline review timing, including guard checks, was about
0.09 ms median for the three relevant proposals, versus no extra planner search.
These are local microtimings, not a scaling result or in-run wall-time savings.

An evaluator logging bug initially held a mutable reference to the start score.
It was corrected to copy scores, and the zero-API frozen-stream experiment was
replayed. Action savings and final scores were unchanged; published records use
the corrected measurements. Paid continuations were not rerun or altered.

REMAINING CLAIM BOUNDARY

This supports a narrow real-game case of useful persistent evidence and a
promising matched-budget LLM result. It does not establish broad task coverage,
guard adequacy across hidden rule changes, robust advantage across independent
instances, global optimality, or final task completion. The next gap is whether
evidence reliably selects productive replacement methods rather than converting
craft loops into movement/inspection loops. The old candidate-coverage bound is
not the mechanism tested here. The existing LaTeX document was not revised in
this experiment turn.
