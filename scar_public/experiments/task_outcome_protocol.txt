V15 prospective development evaluation, 2026-10-17

Objective: main-quest completion within 300 environment actions; then quest
score/stage progress, then action and API cost. No stopping at selected stages.
Use all three previously authorized games: remnant, mark, metropolis. The shared
existing initial snapshots were drawn without a requested fixed seed. No world
edits. Same model/provider, parser, actor system prompt and local solver family.
Compare V14 execute against V15 execute; V14 has not previously been run from
these initial states for a full-budget comparison. Existing STM/LongContext/
ReflAct baselines remain frozen; do not rerun them. Scope attributes for BOTH
arms, explicitly conditional on hidden modifiers not invalidating the guard.

Run one trajectory per arm and game. Exact identical provider requests at the
same step share completed responses. Restore each arm's engine RNG before every
step. Differences after intervention remain stochastic; no significance claim.
These familiar worlds are development tests, not held-out validation. Primary
success is the engine's public 'completed the main quest and passed the game'
report, not a surrogate craft, possession, local plan or inferred completion.
Report failures and ties along with wins; do not change endpoints after results.

V15 candidate ranking: supported task role, retention of constructive remaining
material witnesses, then conditional endpoint action cost. A role-unknown
endpoint can receive a bounded trial, not a completion certificate. A capacity
repair needs a conditional suffix to its endpoint, not merely a short route to
a container. Existing material checks are sufficient witnesses only; their
failure defers autonomy rather than proving global infeasibility. Per-step real
feedback, bounded leases and release on failure/no progress prevent an
unlimited commitment. This ordering is a heuristic, not an estimated success
probability or proof that whole-game success cannot decrease.

Freeze implementation before paid runs. All requests, malformed-output retries,
and failed attempts are charged/audited. No additional LLM review call is added
by V15. Keep complete public traces and source hashes; omit keys and engine
pickle snapshots from publication. Never relabel offline replay as a new game.
