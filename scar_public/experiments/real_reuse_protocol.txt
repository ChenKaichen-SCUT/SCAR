Frozen design before new environment execution, 2026-10-17.

Discovery uses only historical public prefixes from V6 and V8: 67 craft proposals,
22 grounded; one repeated recipe/context family, Metropolis gavel_club. V8 repeated
steps: 174,184,189,207,216,240,250. V6 repeats:163,173. These are development data,
not an independently held-out discovery. All grounds and failures remain recorded.

Primary mechanistic test: restore the real V8 environment before action 184.
Replay the original actor's proposed command stream through action 250 in two
isolated arms. Control executes proposals without cross-query evidence. Treatment
charges and executes the initial admissible test, persists its actual feedback,
and reviews later craft proposals before expensive search, even when the search
quota is exhausted. It skips a proposed command only if (i) its guarded prior
evidence applies; (ii) every surviving profile predicts identical failure with
unchanged physical state; (iii) the original family still contains success
predictions. No return to hidden environment rules or future observations.

This is an intervention on a FROZEN proposal stream, not a free-running LLM
evaluation. All other commands, acquisitions, travel, inspections and failures
remain charged. Both arms start with no evidence. Restored RNG state is part of
the matched checkpoint; no new random seed is chosen. Target endpoint: finish
the same proposal stream. Report actual environment actions, acquisition cost,
later vetoes, quest scores, health, holdings/location/equipment and model mismatch.
Report whether either arm completed the actual main task; equal failure does not
become success. Identical final visible state does not prove hidden-state equality.

Secondary checks: restore each proposed-veto historical checkpoint independently
and actually execute its craft command. This tests predicted failure on the real
environment; do not feed these later outcomes into earlier decisions. Include
no-benefit proposals (all original profiles already predict failure), changed
contexts, and unsupported grounding in the report.

If the frozen-stream test succeeds, run one matched continuation per arm from
the same checkpoint with actual LLM decisions and the same remaining global
300-action budget. The only intentional intervention is persistent evidence use
and a bounded repair request upon a redundant proposal. Reuse the controller-
off result after this run; do not rerun unchanged whole-game baselines. Report
all requests including repairs/retries and charge all environment actions. One
sample per arm is development evidence, not a statistical or optimality claim.

Stop expanding experiments if there is no applicable reuse or if false vetoes /
guard failures invalidate the mechanism. Retain negative results. Do not weaken
guards to obtain positive counts, invent repeated task needs, replenish materials
by mutating state, or claim that avoided failures necessarily improve game score.

Before paid execution: both LLM arms start at checkpoint 0184, immediately AFTER
the shared, real one-action acquisition at step 184 (re-executed in the frozen
stream test). Its pending feedback is processed by each agent on resume. Charge
this acquisition once to each arm when reporting cost from checkpoint 0183.
This prevents independent first LLM samples from replacing the intended common
acquisition. Each arm then has the same 116 remaining environment actions; the
absolute limit remains 300. Same V10 code/prompts, reuse on versus off; only the
on arm stores and uses cross-query exclusions. All calls, including bounded
semantic repairs, are counted. Full checkpoint/RNG and notebook are shared;
the LLM sampling distribution is the same but samples are not paired.
